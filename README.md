# Projeto React Native Expo

## 📱 Visão geral

Este projeto é uma aplicação mobile desenvolvida com React Native e Expo, criada para demonstrar a estrutura básica de um app com interface simples, responsiva e pronta para evoluir com novas funcionalidades.

A aplicação foi construída como base para apresentação de projetos acadêmicos, protótipos ou ideias de produto digital, com foco em simplicidade, organização e facilidade de execução.

## ✨ Objetivo

O objetivo principal deste projeto é apresentar uma solução móvel funcional e bem estruturada, com:

- interface intuitiva;
- arquitetura simples e legível;
- ambiente de desenvolvimento moderno;
- compatibilidade com Android, iOS e web via Expo.

## 🛠️ Tecnologias utilizadas

- React Native
- Expo
- JavaScript
- React
- Node.js

## 🚀 Como executar

### Pré-requisitos

Antes de rodar o projeto, certifique-se de ter instalado:

- Node.js
- npm ou yarn
- Expo CLI (opcional, pois pode ser usado via npx)

### Instalação

```bash
npm install
```

### Execução

```bash
npm start
```

Em seguida, escolha uma opção:

- Android
- iOS
- Web

Ou use diretamente:

```bash
npx expo start
```
